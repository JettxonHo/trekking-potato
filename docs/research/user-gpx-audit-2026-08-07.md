## 1. 范围与结论

本轮审阅以下五份 GPX：

1. `武功山反穿.gpx`
2. `四姑娘二峰.gpx`
3. `2026 五台山.gpx`
4. `2025-08-05 贡嘎西南坡.gpx`
5. `丽江玉龙雪山蓝月谷云杉坪徒步往返线.gpx`

五份文件都是可解析的 GPX 1.1，均含一个 `trkseg`；多日文件在同一段内仍有明确隔夜间隔，
不能据此称为连续活动。轨迹点的坐标、`ele` 和 `time` 字段存在率均为 100%，但武功山有两个
非物理的 `ele=0`，所以字段存在不等于数值全部有效。它们可以作为各自**实际记录路线**的经 Sol
审阅 GPX 几何候选；但没有一份与审计当时的五条试点 exact Variant 相同，因此当时不能补写
旧目标 Variant 字段。TP-D039 后只按各文件的实际路线身份使用，I13 仍等待第五条 GPX。

本轮没有读取误附的个人简历 PDF。原始 GPX 含分享平台账号、轨迹 ID、精确时间和位置等元数据，
未复制到仓库或提交 GitHub；本报告只保留完成来源判断所需的非个人化派生结果。

## 2. 方法

- 使用 XML 解析器验证格式并逐点读取 `trkseg/trkpt`；不把搜索摘要或文件名当作唯一证据。
- 距离为同一轨迹段内相邻点的 Haversine 累加，不跨段连接。
- 活动日按 `Asia/Shanghai` 划分，并用长时间间隔识别隔夜停止；逐日距离不连接两个活动日之间的
  相邻点，因此逐日数值之和会比同一 `trkseg` 的全轨逐点距离略小。这只用于审计，不替代官方日程。
- 升降列是“独立近似复核”：先在同一 `trkseg` 内按相邻点 Haversine 距离建立累计里程，每 20m
  对海拔做线性插值并保留最终点；非正海拔由前一有效值填充，开头则用首个有效值回填；再使用
  以当前点为中心、半径 2 的 5 样本中位窗口，边界只取已有样本；最后把所有相邻正/负变化分别
  累加，不再设置垂直阈值。计算保留到 0.1m，概览表再四舍五入到整数米。同时保留导出扩展中的
  `Distance/ElevationGain/ElevationLoss`。两者接近时仅证明轨迹内部自洽，不证明路线身份。
- exact Variant 匹配使用起终点、天数、关键路标、轨迹范围、海拔和官方点序共同判断。
- GPX 只能支持其实际经过的几何、时间和海拔；不能单独证明当前开放、许可或景区运行状态。

## 5. 逐文件风险与可用边界

### 武功山反穿

- 上海日分段约为 14.126km 和 9.539km，文件自身也建议两日完成。
- 轨迹第一个点和第 5,465 个点为零高程；它们分别接近 556m 的起点 waypoint 和约 1597m 的
  “观音宕·第一日住宿” waypoint。说明坐标点序未断裂，但这两个高程不能直接采用。
- 文件描述的“约 24km、爬升约 2200m”和扩展统计与独立复核量级一致。
- TP-D039 已批准将它用于新 I08；新合同必须建立两日 RouteVariant、unknown 状态和分日 stage，
  不能保留旧一日 mixed 身份。

### 四姑娘二峰

- 上海日分段约为 12.995km 和 19.584km；最高轨迹点为 5254m。
- 起终仅相距 72m，支持两日往返身份；与七日官方行程不是同一粒度。
- TP-D039 已批准二日二峰新 Variant 取代旧七日合同；不得把旧七日的附近峰或日程混入。

### 2026 五台山

- 上海日分段约为 19.287km、31.304km、24.082km。
- 轨迹范围覆盖多个台顶并出现少量异常速度点；即使清洗后也仍是三日大范围穿越。
- 2026-07-31 官方“全域禁止台顶徒步”标题晚于该轨迹日期；历史走过不能证明当前允许，反而必须继续服从 I10a 的 blocked 边界。

### 贡嘎西南坡

- 上海日分段约为 20.638km、14.069km、10.185km。
- waypoint 明确记录偏离主路、河道硬上、绕牦牛等个人路线情况；这些是该次轨迹事实，不能提升为官方推荐点序。
- 即使同为三日，也不能因区域和天数相同就把它映射为 2017 赛事线。

### 蓝月谷云杉坪往返

- 单日约 5.39 小时，几何与升降统计高度自洽。
- 轨迹与 I11 的海拔区间完全分离，不是“冰川公园 4680 观景线”的子段。
- TP-D039 已批准按“蓝月谷—云杉坪徒步往返”重写 I11；类型为纯步行 `trek`，状态缺乏精确
  管理事实时为 `unknown`，不继承旧 4680 tour 身份。

## 6. 后续产品决策

本审计完成时，TP-D037 曾保留旧 exact pilots；该决定随后被人工批准的 TP-D039 取代。当前采用
“官方管理事实 + 经 Sol 审阅社区 GPX”的混合政策，并按轨迹真实身份重定义 Beta 试点：

- 武功山反穿、四姑娘二峰两日、贡嘎西南坡和蓝月谷—云杉坪分别进入 I08、I09、I12、I11；

- 第五条可规划 GPX 由 #77 另行选择和审阅。

本报告的质量数值现在可作为四条替代 Variant 的规划证据，但不是可直接复制的数据合同。每条
Issue 仍需冻结分日、异常处理、坐标解释、采样点和 Source.supports；原始 GPX 继续不入库。
