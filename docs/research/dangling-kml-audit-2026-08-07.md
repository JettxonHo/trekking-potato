# 党岭 KML 轨迹审阅（2026-08-07）

## 结论

用户明确确认该 KML 是其本人轨迹。文件可作为 TP-BETA-001 第五条 full Variant 的 tier B
几何证据，无需转为 GPX；它不证明路线当前开放。路线身份冻结为
`党岭村—葫芦海—卓雍措一日往返`，类型为 `trek`，当前管理状态为 `unknown`。

原始 KML 不进入仓库。本报告只保留产品需要的去标识化派生数据，不保留平台账号、创作者字段、
轨迹/缩略图 ID、精确活动日期和时间、完整点序或可还原个人行程的元数据。

## 文件与质量审阅

- 格式：KML 2.2，包含一个 `gx:Track`。
- 完整性：3,326 个 `gx:coord` 与 3,326 个 `when` 按序一一配对；坐标、三维高程和带时区时间
  解析率均为 100%。
- 时间：一个 `Asia/Shanghai` 活动日，时间严格递增；参考经过时长按既有规则向上取整到整分钟，
  为 `12.18h`。该窗口包含停留时间，适合作为保守的天气评估窗口。
- 连续性：最大相邻空间步长约 `27.65m`，没有超过 `100m` 的跳点；最大时间缺口约
  `11.82min`，缺口两端只相距约 `5.25m`。没有断轨或交通桥。
- 异常：存在一处 1 秒采样形成的瞬时速度异常，但没有对应几何跳点；少量重复坐标符合停留，
  不需要为此过度清洗。
- 高程：有效高程范围约 `3383.1–4341.2m`，无非正或非有限高程。

## 几何派生方法与结果

- 距离：使用半径 `6371008.8m` 的 Haversine，得到 `19.067km`。
- 升降：20m 等距重采样后，以半径 2 的中位滤波处理高程，得到累计上升 `1009.4m`、
  累计下降 `955.8m`。
- 导出扩展值为约 `19.311km / +995.3m / -940.3m`，与独立结果相差约
  `1.27% / 1.41% / 1.65%`，量级一致。
- 形态：起终相距约 `0.892km`；最高点位于全程约中点，去回里程近似对称，双向轨迹大部分
  在 100m 内重合，局部存在自然分叉。因此冻结为 `out_and_back`、`isLoop=false`，不是 loop
  或 point-to-point。
- 天气样点：单日使用两个实际 WGS84 轨迹点，覆盖约 958m 垂直差：
  - 党岭村徒步起点区域：`31.075586, 101.403937, 3383m`
  - 卓雍措方向轨迹高点：`31.051365, 101.359981, 4341m`

## Source.kind 决策

新增通用且向后兼容的 `reviewed_track`，用于经控制端审阅的 KML、GPX 或未来同等轨迹文件；
既有四条 `reviewed_gpx` 保持不变，不执行迁移。`reviewed_track` 表达证据类别而不是文件扩展名，
本条 Source 标题明确写出 KML 2.2 `gx:Track`，避免把 KML 错记为 GPX，也避免为每种文件格式
持续扩张枚举。

这是一项内部静态目录的 additive 变更，不改变云函数公共响应契约，不引入生产 KML parser、
上传能力、依赖、数据库迁移或原始文件存储。
